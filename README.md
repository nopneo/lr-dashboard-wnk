# LR Dashboard — แดชบอร์ดงานห้องคลอด (HOSxP)

หน้า infographic แบบเว็บ (Flask) อ่านข้อมูลสดจาก HOSxP **อ่านอย่างเดียว** สำหรับงานห้องคลอด — เวอร์ชัน 0.1.1
แสดงเฉพาะจำนวนนับ · รายชื่อเบื้องหลังตัวเลขดูได้หลังเข้าสู่ระบบ · ติดตั้งและ **ขั้นตอนตรวจก่อนใช้** ดู [INSTALL.md](INSTALL.md)

## หน้าจอ

| หน้า | เนื้อหา |
|---|---|
| `/` ภาพรวม | การ์ด การคลอดทั้งหมด · คลอดปกติ · มีภาวะแทรกซ้อน/หัตถการ · ส่งต่อ (เทียบปีงบก่อน) · กราฟแท่งซ้อนรายเดือน · สัดส่วนผู้มาคลอด · ตัวชี้วัดคุณภาพ 9 ช่อง · ช่วง 7 วันล่าสุด · ปุ่มเลือกปีงบ |
| `/yearly` | ตาราง “สถิติบริการ” 19 แถว (ตามแบบรายงานห้องคลอด) × 6 ปีงบ |
| `/check` | Data Audit — รหัสที่แอปใช้เทียบกับที่พบในข้อมูล + กระทบยอดจำนวนคลอด 4 แหล่ง (เฉพาะ LAN) |
| `/list` | รายชื่อเบื้องหลังตัวเลข 15 กลุ่ม (ต้อง login · บันทึกทุกการเปิดดู) |
| `/export.jpg` `.png` `.pdf` | ส่งออกหน้าภาพรวม (ไม่มีข้อมูลรายคน ไม่มีแถบเตือน) |

## นิยามตัวชี้วัด (หน่วยนับ = มารดา 1 การคลอด หรือทารก 1 ราย · ปีงบ 1 ต.ค.–30 ก.ย.)

ทุกรหัสตั้งได้ด้วย env `LR_*` (ค่าเริ่มต้นดูใน [.env.example](.env.example)) แล้วตรวจที่หน้า `/check`

| ตัวชี้วัด | นิยาม | ตาราง HOSxP |
|---|---|---|
| มารดาที่คลอด | แถวใน `ipt_pregnancy` ที่ `labor_date` ในช่วง **และมีหลักฐานการคลอด** (มีทารกใน `ipt_labour_infant` หรือ Dx O80–O84/Z37) ตัดแท้ง | `ipt_pregnancy`, `ipt_labour_infant`, `iptdiag` |
| คลอดปกติ / ผิดปกติ | ปกติ = มี Dx O80 และไม่มีภาวะแทรกซ้อน (O72, O60, O13–O16, O63, O68, O42) หรือหัตถการ · ผิดปกติ = ที่เหลือ | `iptdiag`, `iptoprt` |
| ผ่าท้อง · คีม · สุญญากาศ · ท่าก้น | ICD-9 74.x · 72.0–72.4 / O81.0–3 · 72.7 / O81.4 · 72.5x / O83.0–1 | `iptoprt`, `iptdiag` |
| ครรภ์แฝด | `twin_child_count ≥ 2` หรือทารก ≥ 2 ราย/การคลอด | `ipt_pregnancy`, `ipt_labour_infant` |
| คลอดก่อนถึง รพ. (BBA) | `infant_delivery_type_id` ใน `LR_BBA_TYPES` (ค่าเริ่มต้น 3) | `ipt_labour_infant` |
| เด็กเกิดทั้งหมด / มีชีพ / ไร้ชีพ | ทารกใน `ipt_labour_infant` · ไร้ชีพ = Dx P95, Z37.1/.3/.4/.6 | `ipt_labour_infant`, `iptdiag` |
| เด็ก 0–7 วันตาย | ทารกมีชีพที่เสียชีวิต (`ipt_newborn.dead` หรือ `infant_dchstts` 08/09) ภายใน 7 วัน | `ipt_labour_infant`, `ipt_newborn`, `ipt` |
| Apgar 1 นาที ≤ 7 | `apgar_score_min1 ≤ 7` (ค่าว่างไม่นับ) | `ipt_labour_infant` |
| มารดา Syphilis / HIV / Hep B | พบผลบวกของ VDRL·TPHA / Anti-HIV / HBsAg **ครั้งใดก็ได้ตลอดการตั้งครรภ์** — ผลตอนคลอด (`ipt_labour_lab`) และ lab_order ของ HN เดียวกันตั้งแต่ 300 วันก่อนคลอดถึง 7 วันหลังคลอด (แบบเดียวกับ ANC dashboard) · รหัส lab เลือกจากชื่อรายการ หรือตั้ง `LR_LAB_*_ITEMS` · ผลพิมพ์มือจัดบวก/ลบ/ไม่ชัด (“ไม่ชัด” ไม่นับทั้งสองฝั่ง) | `ipt_labour_lab`, `lab_head`, `lab_order` |
| มารดา Amphetamines | ผลบวกของ lab ปัสสาวะ Methamphetamine (`LR_LAB_AMPH`) ตลอดการตั้งครรภ์ — วิธีเดียวกับแถวข้างบน | `lab_head`, `lab_order` |
| มารดาติดสุรา/ยาเสพติด | ข้อ 17 “ติดยาเสพติด ติดสุรา” ของแบบคัดกรองครรภ์เสี่ยง ANC ติ๊ก ‘Y’ (`LR_SUBSTANCE_FORM_ITEMS`) จับคู่ด้วย HN + ช่วงตั้งครรภ์ · **ไม่รวมบุหรี่/คนใกล้ชิดสูบบุหรี่ (ไม่มีข้อมูลในฐาน)** · ไม่มีมารดาจับคู่ได้เลย = “ไม่มีข้อมูล” | `person_anc`, `person_anc_classifying` |
| ส่งต่อ | มารดาที่รับไว้ห้องคลอดแล้วส่งต่อโดยยังไม่ได้คลอดที่ รพ. (`referout.vn` = AN ใน `ipt_pregnancy`) · ไม่นับเป็นการคลอดที่ รพ. | `referout`, `ipt_pregnancy` |

ตัวชี้วัดที่ไม่มีข้อมูลแสดง “ไม่มีข้อมูล” เสมอ ไม่แสดงเป็น 0 · รายละเอียดการตรวจฐานจริงดู [docs/schema-notes.md](docs/schema-notes.md)

## พัฒนา / ทดสอบ

```bash
pip install -r requirements.txt && pip install pytest
python -m pytest tests -q          # ไม่ต่อฐานข้อมูลจริง
python setup_check.py              # ตรวจสภาพแวดล้อมกับฐานจริง
python build_dist.py               # สร้างชุดแจก dist/lr_dashboard-<version>.zip
```

โครงสร้าง: `queries.py` (SQL) → `loader.py` → `metrics.py` (นิยาม — ฟังก์ชันบริสุทธิ์) → `app.py` + `templates/` ·
`audit.py` ใช้ queries ชุดเดียวกัน · ออกแบบและแผนงานอยู่ใน `docs/superpowers/`
