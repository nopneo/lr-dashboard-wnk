## 1. จุดประสงค์ (ที่ตกลงกันแล้ว)

- ผู้ใช้: ผู้บริหาร/หัวหน้างาน (รายงานผลงานรายปี) **และ** พยาบาลห้องคลอด (ใช้ประจำวัน)
- แทนตารางพิมพ์มือ `kpi.jpg` (13 ตัวชี้วัด × ปีงบ 2565–2569) ด้วยตัวเลขที่คำนวณสดจาก HOSxP
- รูปแบบ: Flask app อ่านอย่างเดียว หน้า infographic เดียว แบบเดียวกับ `ANC_dashboard` / `er_dashboard`
- **`kpi.jpg` ใช้เป็นโครงตารางเท่านั้น** — ตัวเลขในภาพ (631–856 คลอด/ปี) ไม่ตรงกับ HOSxP ของเรา
  (~80 คลอด/ปี) จึงไม่ใช้เป็นค่าอ้างอิง · `S__34177042_0.jpg` เป็น mockup ของ รพ. อื่น ใช้เป็นแนวสไตล์เท่านั้น
  (ใช้โลโก้/ชื่อ รพ.วังน้ำเขียว)

**เกณฑ์สำเร็จ:** (1) ยอดคลอดรายปีงบ 2565–2569 จากแอป = 92 / 85 / 92 / 72 / 78 (ตรงกับที่ตรวจในฐานแล้ว)
(2) ทุกรหัสที่โค้ดสมมติไว้โผล่ในหน้า `/check` พร้อมสถานะ "ใช้ vs พบ" (3) ตัวชี้วัดที่ฐานไม่มีข้อมูลแสดง
"ไม่มีข้อมูล" ไม่ใช่ 0 (4) หน้าหลักไม่มีข้อมูลรายคน

## 3. หน้าจอ

1. **หน้าหลัก `/`** (เลือกปีงบ + ช่วงเดือน)
   - การ์ด KPI: คลอดทั้งหมด · คลอดปกติ · มีภาวะแทรกซ้อน · ส่งต่อ (พร้อม % เทียบปีงบก่อน)
   - กราฟแท่งซ้อนรายเดือน (ปกติ / ภาวะแทรกซ้อน / ส่งต่อ) · โดนัทสัดส่วน
   - ตัวชี้วัดคุณภาพ (ตารางเล็ก): Birth asphyxia, PPH (O72), คลอดก่อนกำหนด (O60), PIH/PE (O13–O16),
     คลอดยาก/เจ็บครรภ์ยืดเยื้อ (O63), ทารก LBW, Admit ต่อ/ส่งต่อ
   - จำนวนเคสล่าสุด 7 วัน (นับเท่านั้น)
2. **ตารางผลงานรายปี `/yearly`** — 13 แถวตาม `kpi.jpg` × ปีงบ ย้อน 5 ปี + แนวโน้ม
3. **Data Audit `/check`** — ทุกรหัสที่แอปใช้ "แอปใช้ vs พบในข้อมูล" + ค่า env ที่ควรตั้ง + กระทบยอดจำนวนคลอด 4 แหล่ง
4. **รายชื่อหลังตัวเลข `/list/...`** — ต้องเข้าสู่ระบบ (กลไกเดียวกับ ANC dashboard) · ไม่มีในหน้าหลัก/ไฟล์ส่งออก
5. ส่งออก JPG/PDF (ไม่ติดแถบเตือน "ยังไม่ตรวจ")

## 4. นิยามตัวชี้วัด 13 แถว (ตามลำดับใน kpi.jpg)

หน่วยนับ: แม่ = 1 การคลอด (AN) · เด็ก = 1 ราย · ปีงบ = 1 ต.ค.–30 ก.ย. · **ทุกรหัสตั้งด้วย env ค่าเริ่มต้นตามนี้ แล้วตรวจใน /check**

| # | ตัวชี้วัด | นิยามเริ่มต้น | แหล่ง |
|---|---|---|---|
| 1 | จำนวนมารดาที่คลอด | `ipt_pregnancy` ที่ `labor_date` ในช่วง **และมีหลักฐานการคลอด** (มีทารกใน `ipt_labour_infant` หรือ Dx ขึ้นต้น `LR_DELIVERY_ICD10` = O80–O84, Z37) · ตัดแท้ง · (ฐานจริงมีแถวรอคลอด/ไม่คลอดปนอยู่ ธง `abort` เป็น NULL ทั้งตาราง) | `ipt_pregnancy`, `ipt_labour_infant`, `iptdiag` |
| 1.1 | คลอดปกติ | Dx ใดก็ได้ใน AN = O80 และไม่มีภาวะแทรกซ้อน/หัตถการข้างล่าง `LR_NORMAL_ICD` | `iptdiag` |
| 1.2 | คลอดผิดปกติ | = ข้อ 1 − ข้อ 1.1 | — |
| – | ผ่าท้องคลอด | icd9 74.x `LR_CS_ICD9` (ที่ รพ.นี้คาดว่า 0) | `iptoprt` |
| – | ใช้คีม | icd9 72.0–72.4 / ICD O81.0–O81.3 `LR_FORCEPS_*` | `iptoprt`, `iptdiag` |
| – | เครื่องดูดสุญญากาศ | icd9 72.7 / O81.4 `LR_VACUUM_*` | เหมือนกัน |
| – | คลอดท่าก้นทางช่องคลอด | O83.0–O83.1 หรือ icd9 72.5x `LR_BREECH_*` | เหมือนกัน |
| 2 | ครรภ์แฝด | `twin_child_count ≥ 2` หรือเด็ก ≥ 2 ราย/การคลอด | `ipt_pregnancy`, `ipt_labour_infant` |
| 3 | คลอดก่อนถึง รพ. (BBA) | `ipt_labour_infant.infant_delivery_type_id in ('3')` (`LR_BBA_TYPES` — ค่าเดียวกับที่ ANC dashboard ใช้) · **ยืนยันใน /check ว่ารหัส 3 ตรงความหมายของ รพ. นี้** | `ipt_labour_infant` |
| 4 | เด็กเกิดทั้งหมด | นับ `ipt_labour_infant` ที่ `birth_date` ในช่วง | `ipt_labour_infant` |
| 5 | เด็กเกิดมีชีพ | ข้อ 4 − ข้อ 6 | — |
| 6 | เด็กเกิดไร้ชีพ | ICD P95, Z37.1/.3/.4/.6 `LR_STILLBIRTH_*` · ทารกเสียชีวิต = `ipt_newborn.dead='Y'` หรือ `infant_dchstts in ('08','09')` `LR_DEAD_DCHSTTS` (ตามที่ ANC ใช้) — **ฐานนี้พบ dchstts เพียง 03/04/05 จึงต้องยืนยันใน /check** | `ipt_labour_infant`, `ipt_newborn`, `iptdiag` |
| 7 | ตาย 0–7 วัน | เด็กมีชีพที่เสียชีวิต (นิยามข้อ 6) และ `datediff(dchdate, birth_date) ≤ 7` | `ipt_labour_infant`, `ipt` |
| 8 | Apgar 1 นาที ≤ 7 | `apgar_score_min1 ≤ 7` (นับค่าว่างแยกใน /check) | `ipt_labour_infant` |
| 9 | มารดา Amphetamines | ผลบวกของ lab ปัสสาวะที่ผูก AN มารดา (`lab_head.vn = AN`) รหัส `LR_LAB_AMPH` (ค่าเริ่มต้นของ รพ.นี้ 139, 590, 2104, 1992) · ผลพิมพ์มือจัดบวก/ลบแบบ VDRL | `lab_head`, `lab_order` |
| 10 | มารดาติดสุรา/บุหรี่/ใกล้ชิดสูบบุหรี่ | **ไม่พบแหล่งในฐานของห้องคลอด** (ค้นคอลัมน์ smok/alcohol/drink ทั้งฐานแล้ว ไม่มีตาราง LR/ANC) → แสดง "ไม่มีข้อมูล" จนกว่า รพ. จะบันทึก | — |
| 11 | มารดา Syphilis | VDRL/RPR reactive ตอนคลอด | `ipt_labour_lab` (+ `lab_order`) |
| 12 | มารดา HIV | Anti-HIV positive | เหมือนกัน |
| 13 | มารดา Hep B | HBsAg positive | เหมือนกัน |

ผลพิมพ์มือ lab จัดกลุ่ม บวก / ลบ / ไม่ชัด แบบเดียวกับ ANC (ไม่ชัดไม่นับเป็นลบ)
แถว 9–13 ถูกทำเครื่องหมายแดงใน `kpi.jpg` และปี 2569 ว่าง — แอปแสดงเป็น "กำลังตรวจสอบข้อมูล" จนกว่าผ่าน audit

## 5. สถาปัตยกรรม

คัดแบบโครง `ANC_dashboard` (ไฟล์ไม่เกินหนึ่งหน้าที่/ไฟล์):

```
LR_dashboard/
  app.py          routes, PrefixMiddleware, login
  config.py       env + ค่าเริ่มต้นรหัส (LR_*), ปีงบ
  db.py           เชื่อมต่อ MariaDB อ่านอย่างเดียว (+ โหมด bms ภายหลัง)
  queries.py      SQL ล้วน รับ config ไม่มีรหัสตายตัว
  metrics.py      คำนวณ 13 แถว + ตัวชี้วัดคุณภาพจากผล queries (ทดสอบแยกได้)
  audit.py        สร้างผล "ใช้ vs พบ" และกระทบยอด 4 แหล่ง
  render.py       ส่งออก JPG/PDF
  templates/ static/
  setup_check.py  ตรวจสภาพแวดล้อมก่อนใช้ (✔/⚠/✘, exit 1 เมื่อมี ✘)
  tests/  docs/  INSTALL.md  CHANGELOG.md  README.md  LICENSE  Dockerfile
  .github/ISSUE_TEMPLATE/bug_report.yml
```

Data flow: HOSxP → `queries` (นับ) → `metrics` (นิยาม) → `app`/template · `audit` ใช้ `queries` ชุดเดียวกัน
เพื่อให้ตัวเลขใน /check กับหน้าหลักมาจากแหล่งเดียว

## 6. ความเป็นส่วนตัวและการ deploy

- หน้าหลัก/ส่งออก = จำนวนนับเท่านั้น · รายชื่อหลังเข้าสู่ระบบ · `/check` เปิดเฉพาะ LAN
- ไม่เก็บรหัสในไฟล์ · รหัสผ่านผู้ใช้ใช้ `pbkdf2:sha256`
- deploy ตามสกิล `wnkhos-deploy` (sub-path `/lr/` บน 443, systemd + gunicorn, พอร์ตว่างที่เลือกตอน deploy)
- ตามกฎ CLAUDE.md: `setup_check.py`, หน้า /check, แถบ "ยังไม่ตรวจ" จน `LR_DATA_AUDITED=1`, INSTALL.md ข้อ 0, issue template

## 9. ประเด็นที่ต้องยืนยันตอน implement (ไม่ใช่ค่ากำหนดที่เดาไว้)

**ยืนยันแล้ว (2026-11-12, ตรวจฐานจริงแบบอ่านอย่างเดียว):**
1. BBA = `infant_delivery_type_id '3'` พบ 8 ราย/5 ปี (รหัส '1' = คลอดปกติ 407 ราย) — ใช้ตามค่าเริ่มต้น
2. `dchstts` master: 08 = Dead Still Birth, 09 = Dead (ตรงกับค่าเริ่มต้น) · ทารกใน 5 ปีมีเพียง 03/04/05 → ไม่มีทารกเสียชีวิต/ตายคลอด (ไม่ใช่ข้อผิดพลาดของรหัส)
3. สุรา/บุหรี่: ไม่มีแหล่งข้อมูล → "ไม่มีข้อมูล" (ดู §4 แถว 10)
4. `ipt_labour_lab`: `lab_id` 1 = VDRL, 2 = Anti HIV, 3 = HBsAg · `lab_value` พิมพ์มือ (NR/neg/-ve/Non reactive/1:8 ฯลฯ) — `classify_result` รองรับทั้งหมดที่พบ
5. ส่งต่อ = `referout.vn` เท่ากับ AN ในตาราง `ipt_pregnancy` ของมารดาที่ยัง**ไม่ได้คลอดที่ รพ.** (18–21 ราย/ปี) · ส่งต่อทารก (Dx Z38/P..) อยู่ใต้ AN ของทารก ไม่นับ

**กระทบยอดผ่าน:** ยอดคลอดปีงบ 2565–2569 = 92 / 85 / 92 / 72 / 78 ตรงกับ `ipt_labour_infant` ทุกปี
